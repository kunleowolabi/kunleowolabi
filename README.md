Electrical engineer building energy data systems and software.

I investigate energy problems and build solutions to them, from physical systems to data and software. The problem picks the tools, not the other way round.

## Projects

**[Rete](https://explorerete.com)** · [source](https://github.com/kunleowolabi/rete)
Open data on Nigeria's electricity supply against modelled demand. Collects the system operator's data hourly, reconciles three plant-naming schemes, and traces every figure to its source.
*Python · PostgreSQL/PostGIS · AWS · Terraform · React*

**[Arrhen](https://github.com/kunleowolabi/arrhen)**
Open-source greenhouse-gas accounting following the GHG Protocol. Records the emission factor and GWP version behind every figure, and flags estimates instead of presenting them as measurements.
*Python · FastAPI · PostgreSQL/PostGIS · React*

**[Rubeeq](https://github.com/kunleowolabi/rubeeq-etl)**
PDF to queryable data. Sends only scanned pages to a vision model, infers the schema from the document itself, and loads the result into DuckDB.
*Python · pdfplumber · Claude API · DuckDB*
